# Talent icons

Project-owned synthetic artwork created for OpenKal on 2026-10-19 using the built-in
OpenAI image generation tool, from the documented talent effects. No external
reference image or game asset was supplied. Distributed as project-owned artwork
under GPL-3.0-or-later. The PNG bytes are retained in
[`source/Atlas.png`](source/Atlas.png); [`source/Prompt.txt`](source/Prompt.txt)
contains the generation prompt. Each exported PNG is one cell
of the 4-column, 3-row atlas, split without painting or retouching. Runtime BMPs
are generated by the existing icon converter. Grayscale is computed by the client
from the same icon, preserving the silhouette and alpha.

Regenerate the icon templates with `python3 tools/export_talent_icons.py` from
the repository root. The `source/` directory is excluded from runtime icon
conversion and `config.pak`.

Node families share icons; their ordinal and point cost distinguish individual
nodes. A gold border marks pending choices, green marks committed choices.
Only committed nodes use the colored texture.
