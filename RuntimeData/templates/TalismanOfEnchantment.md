# Talisman of Enchantment artwork

`talismanOfEnchantment.png` is the unnumbered scroll artwork generated
for OpenKal on 2026-10-24 with the built-in Imagegen tool and no external reference
artwork. The same tool edited that project-owned image into
`talismanOfEnchantmentI.png`, placing an antique gold Roman numeral directly in
the existing violet magic sigil. This first painted variant was the sole reference
for the four further edits: `talismanOfEnchantmentII.png`,
`talismanOfEnchantmentIII.png`, `talismanOfEnchantmentIIII.png` and
`talismanOfEnchantmentV.png`. Each changes the central numeral while retaining
the parchment, scroll silhouette, bronze ornaments, blue gem and violet runes.
The four-stroke spelling IIII is intentional.

All six PNGs retain real alpha transparency and are distributed with OpenKal
under GPL-3.0-or-later. No proprietary artwork was consulted or imported.
The existing CMake icon pipeline converts each source into its own transparent
32 by 32 BMP and packages it in `config.pak`. Definitions 23022–23026 reference
the five numbered image keys. The numeral is part of the bitmap illustration;
the UI adds no rank label, rectangle or frame. The unnumbered source remains
available as the project-owned edit reference.

## Generation

Generation prompt:

> Use case: stylized-concept. Asset type: original OpenKal fantasy MMORPG inventory item icon, Talisman of Enchantment, readable at 32x32 pixels. One aged ivory paper talisman with rolled edges and an engraved bronze clasp, glowing violet geometric rune, a small blue magical glint. Bold simple silhouette filling most of a square, slightly tilted, hand-painted realistic parchment and metal in a classic Korean fantasy game style. Fully transparent background and real alpha. No frame, no ground, no lettering, no logo, no watermark, no external reference artwork. Generate a single centered talisman only. This is an original project game asset.
